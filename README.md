# typst-swiss-cv

*A collection of templates for CVs in Switzerland using Typst.*

## Installation

You can install the package locally by running:

```sh
./scripts/package @local
```

It is recommended that you get the Liberation and Alegreya Sans font families.
You can get it from
GitHub ([liberationfonts/liberation-fonts](https://github.com/liberationfonts/liberation-fonts), [huertatipografica/Alegreya-Sans](https://github.com/huertatipografica/Alegreya-Sans))
